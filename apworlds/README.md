Hier deine .apworld-, .yaml- oder .yml-Dateien ablegen.

Danach in AP Chaos Bridge → Spielekatalog → Ordner neu einlesen.
Beim Start wird der gespeicherte Ordner ebenfalls eingelesen.

Für die APworld-Analyse muss Python 3.10 oder neuer installiert sein.
Die Bridge importiert oder installiert die Python-Worlds nicht, sondern liest ihre Deklarationen.
Eine YAML-Vorlage lässt sich auch ohne Python im Spielekatalog bearbeiten.

Weitere Schritte stehen in ../ANLEITUNG.md.
